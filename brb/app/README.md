# BRB app (React Native, Expo)

Watch and control the coding agents running in cmux on your Mac. See `../docs/app-setup.md` for the free way to run it on an iPhone.

    cd brb/app
    npm install      # also installs and builds ../protocol
    npx expo start   # scan the QR code with Expo Go on your phone

Checks: `npm test` (type check plus logic tests).
